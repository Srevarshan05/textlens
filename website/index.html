DEVELOPER WORKFLOWS

Small snippets
Complete workflows

Use the same clear Python surface from a one-file script to a local document processing service

CORE OCR01

Read a document

Start with the modern OCR API for local images and PDFs

from textlens import OCR

ocr = OCR(model="glm-ocr")
text = ocr.read("invoice.png")
print(text)
BATCH OCR02

Process a folder

Export structured results with retries and a live dashboard at localhost:8765

from textlens.batch import BatchOCR

batch = BatchOCR(model="glm-ocr",
                 workers=1)
results = batch.run("./documents")
LOCAL API03

Serve OCR over REST

Start a local FastAPI service with automatic Swagger interface

import textlens

textlens.serve(
    host="127.0.0.1",
    port=8000
)
# /docs → Swagger UI

MODEL CATALOG

Four capable backends
One consistent surface

TextLens lazy-loads vision language models so you can switch backends by changing one parameter

glm-ocr Default

General document OCR, tables, and formula extraction. Strong balance of accuracy and VRAM efficiency

6 GB VRAM0.9B params
lighton-ocr Academic

Academic documents, multi-column research papers, and multi-language structured text

8 GB VRAM1B params
hunyuan-ocr Structured

Complex document layouts, mixed chart/text pages, and schema-constrained JSON extraction

8 GB VRAM~1B params
smolvlm Lightweight

Ultra-compact VLM for laptop GPUs, lower VRAM footprints, and quick local testing
