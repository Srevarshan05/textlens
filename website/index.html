DEVELOPER WORKFLOWS

Small snippets
Complete workflows

Use the same clear Python surface from a one-file script to a local document processing service

CORE OCR01

Read a document

Start with the modern OCR API for local images and PDFs

from textlens import OCR

ocr = OCR(model="glm-ocr")
text = ocr.read("invoice.png")
print(text)
BATCH OCR02

Process a folder

Export structured results with retries and a live dashboard at localhost:8765

from textlens.batch import BatchOCR

batch = BatchOCR(model="glm-ocr",
                 workers=1)
results = batch.run("./documents")
LOCAL API03

Serve OCR over REST

Start a local FastAPI service with automatic Swagger interface

import textlens

textlens.serve(
    host="127.0.0.1",
    port=8000
)
# /docs → Swagger UI
