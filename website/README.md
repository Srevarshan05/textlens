# TextLens website

Source of [textlens-website.vercel.app](https://textlens-website.vercel.app) — the landing page and
docs overview for [TextLens](https://github.com/Srevarshan05/textlens). Static HTML/CSS/JS, no build step;
Vercel deploys every push to `main`.

Preview locally:

```bash
python -m http.server 8080
```

Then open http://localhost:8080. The full documentation lives in the main repo's
[`docs/`](https://github.com/Srevarshan05/textlens/tree/main/docs) folder.
