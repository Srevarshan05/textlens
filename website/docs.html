GET STARTED

What is TextLens?

TextLens is a local, VLM-powered OCR framework for Python. It turns images and PDFs into useful text while keeping model selection, CUDA checks, batch processing, and local serving in one reusable developer workflow.

Local by design

Your files stay on your computer. Most supported engines are vision-language models (VLMs), so an NVIDIA CUDA GPU is strongly recommended for practical performance.

Apple Silicon / MPS

MPS acceleration is on the roadmap. Initial support for Apple Silicon chips is in active development and will be released as a future update.

The problem we solved

Developers repeatedly rebuild the same OCR setup: choose a model, load images, render PDFs, check GPU VRAM, manage folders, handle retries, export results, and expose an API.

TextLens makes those pieces reusable through a clear Python API so you write it once and move on.

  • One input layer for images, PDFs, URLs, bytes, and Pillow images
  • One catalog with model, parameter, and VRAM guidance
  • One BatchOCR workflow for folder-scale processing with a live dashboard
  • One local REST API with auto-generated Swagger documentation
  • One CLI to check hardware, manage models, and run inference

Installation

TextLens uses optional dependency groups. Install only what your use case needs:

Inference only (OCR + BatchOCR)

pip install "textlens-srevarshan[inference,ui]"

Inference + REST API server

pip install "textlens-srevarshan[inference,ui,server]"

Live model discovery from Hugging Face

pip install "textlens-srevarshan[inference,ui,catalog]"

Everything

pip install "textlens-srevarshan[all]"

From source

git clone https://github.com/Srevarshan05/textlens.git cd textlens pip install -e ".[inference,ui,server,catalog]"

NVIDIA CUDA setup

TextLens VLMs require CUDA for practical performance. Complete these steps once per machine:

  1. Install the latest NVIDIA GPU driver for your card (RTX 30xx/40xx/50xx series).
  2. Verify the driver: nvidia-smi — note the CUDA version shown in the top-right corner.
  3. Install the matching PyTorch CUDA wheel from pytorch.org/get-started/locally
  4. Run textlens doctor to confirm the full stack is detected correctly.
You do not need the full CUDA Toolkit

The PyTorch CUDA wheel includes the required runtime libraries. Only the NVIDIA GPU driver is a system-level requirement.

Basic OCR

The OCR class is the main entry point. It auto-detects CUDA and loads the selected model on first use.

from textlens import OCR # Auto-detects CUDA ocr = OCR(model="glm-ocr") # Read an image text = ocr.read("invoice.png") print(text) # Read from URL text = ocr.read("https://example.com/scan.png") # Force a specific device ocr = OCR(model="glm-ocr", device="cuda")

PDF processing

Every backend supports PDF input natively through the unified load_input_images utility.

from textlens import OCR ocr = OCR(model="glm-ocr") # All pages text = ocr.read("report.pdf") # Specific page (1-indexed) text = ocr.read("report.pdf", page=1) # Multiple pages, custom DPI text = ocr.read("report.pdf", page=[1, 2, 3], dpi=300)

Multi-page output is formatted as:

--- Page 1 --- extracted text from page one... --- Page 2 --- extracted text from page two...

BatchOCR

Process an entire folder of PDFs and images in parallel. TextLens handles queuing, workers, retries, structured exports, and a live monitoring dashboard at http://localhost:8765.

from textlens.batch import BatchOCR batch = BatchOCR( model="glm-ocr", workers=1, # 1 worker per GPU to avoid VRAM duplication output_format="json", # json | markdown | csv | txt output_dir="./results", retries=2, enable_dashboard=True, # http://localhost:8765 ) results = batch.run("./documents")

Job controls

# Available while a batch job is running batch.pause() # In-flight tasks finish, new ones wait batch.resume() # Resume from paused state batch.cancel() # Stop workers after current task batch.retry_failed() # Re-queue all permanently failed files # Runtime reconfiguration — no restart needed batch.reconfigure(workers=2) batch.reconfigure(output_format="markdown")

Callbacks

def on_done(task): print(f"Done: {task.source_path.name} — {task.duration_sec:.2f}s") def on_fail(task): print(f"Failed: {task.source_path.name} — {task.error}") results = batch.run("./docs", on_file_complete=on_done, on_file_failed=on_fail, )
GPU VRAM tip

Use workers=1 on a single GPU. Each worker loads a full copy of the model — two workers on a 6 GB GPU will likely cause an out-of-memory error.

TextLens Doctor

Run textlens doctor before downloading any model. It checks CUDA availability, GPU model, VRAM, PyTorch installation, CPU, RAM, and recommends which TextLens models are compatible with your machine.

$ textlens doctor GPU NVIDIA GeForce RTX 4050 Laptop GPU VRAM 6.0 GB ✓ Available CUDA ✓ PyTorch CUDA enabled RAM 16 GB Model recommendations: ✓ glm-ocr — compatible (needs 6 GB) ! lighton-ocr — needs 8 GB VRAM ! hunyuan-ocr — needs 8 GB VRAM ✓ smolvlm — compatible (needs 2 GB)
# Python API equivalent import textlens info = textlens.get_hardware_info() print(info.gpu_name, info.vram_gb)

Live model discovery

Requires the catalog extra. Searches Hugging Face by model name and compares published parameter counts and VRAM requirements against your detected hardware.

# Interactive search (prompts for model name) $ textlens discover # Direct name search $ textlens discover GLM-OCR --compatible-only $ textlens discover DeepSeek-OCR --limit 5 $ textlens discover PaddleOCR-VL --include-unknown # Force a fresh fetch (bypasses 15-minute cache) $ textlens discover GLM-OCR --refresh
Model names only

Discovery searches by model name, not use-case keywords. Enter a real model name such as GLM-OCR, DeepSeek-OCR, or LightOnOCR.

REST API server

Requires the server extra. Launches a FastAPI service with automatic Swagger documentation.

import textlens textlens.serve(host="127.0.0.1", port=8000)

Open http://127.0.0.1:8000/docs for the interactive Swagger UI.

POST /api/v1/ocr — file upload

# cURL curl -X POST "http://localhost:8000/api/v1/ocr" \ -F "file=@invoice.png" \ -F "prompt=Text Recognition:" # Python import requests with open("invoice.png", "rb") as f: r = requests.post("http://localhost:8000/api/v1/ocr", files={"file": f}) print(r.json()["text"])

FAQ

Is TextLens cloud-based?

No. TextLens is designed for local OCR. Images and PDFs are processed on your machine by the model you configure. No data leaves your computer.

Do I need an NVIDIA GPU?

Most supported engines are VLMs so an NVIDIA CUDA GPU is strongly recommended. CPU fallback exists but is substantially slower, especially for multi-page PDFs and batch workloads.

Does BatchOCR support PDFs?

Yes. All four backends support PDF input. PDF pages are rendered to images internally at the configured DPI before inference.

Can I use TextLens without downloading models first?

Models are downloaded from Hugging Face on first use and cached locally. Use textlens model install <id> to pre-download a model before running a job.

What is the fastest model?

smolvlm is the fastest and uses the least VRAM (256M parameters, 2 GB). For accuracy-critical workloads, glm-ocr is the recommended default.
